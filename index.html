01什麼是 Vibe Coding？

⏱ 約 5 分鐘📖 只要讀
一句話重點你負責說「想要什麼」，AI 負責寫程式；你看結果、再說哪裡要改，一直循環到滿意。

這個詞是 AI 研究者 Andrej Karpathy 在 2025 年初提出的。他形容一種新的寫程式方式：不必逐行看懂程式碼，而是用平常講話的方式描述需求，看 AI 做出來的結果，覺得哪裡不對就再說一次，像是跟著「感覺（vibe）」一路調整下去。

跟「傳統寫程式」差在哪？

🧱 傳統寫程式

先花幾個月學語法（HTML、CSS、JavaScript……），再一個字一個字打出程式碼。錯一個符號，畫面可能就壞掉。

像是自己學木工，從鋸木頭開始做一張桌子。

🎬 Vibe Coding

你像「導演」或「客戶」：描述畫面、提出修改意見。AI 像一位很快、很有耐心的工程師，負責動手。

像是跟木工師傅說：「我想要一張圓形、淺色、可以放兩杯咖啡的小桌子。」

它適合做什麼？

✅ 很適合
個人網頁、作品集、活動邀請頁、小遊戲、記帳表、待辦清單、旅行行程頁
🤔 要多花心思
需要登入、存資料、多人一起用的 App——可以做，但建議先熟悉基本觀念
🚫 先別碰
涉及金流、個資、醫療等「出錯會造成真實損失」的系統
名詞小辭典：程式碼（Code）給電腦看的「食譜」。網頁其實就是一份或幾份文字檔，瀏覽器讀了之後，把它畫成你看到的畫面。Vibe coding 就是請 AI 幫你寫這份食譜。

03Token 是什麼？怎麼計費？

⏱ 約 8 分鐘💰 讀完就知道錢花在哪
一句話重點Token 是 AI 讀和寫文字的「計量單位」。新手用月費方案最安心：每月固定費用，用完額度只會暫停，不會被多扣錢。

Token = AI 的「字數單位」

AI 不是一個字一個字讀，而是把文字切成一小塊一小塊，每一塊叫一個 token。大概的感覺：

英文：約 4 個字母 ≈ 1 token
Make me a webpage
5 個 token
中文：約 1 個字 ≈ 1–2 token
幫我做一個網頁
約 7–10 個 token（依模型而定）

為什麼 vibe coding 特別「吃」token？

所以：一件事做完，就開一個新對話。這是最簡單的省錢（也省額度）方法。

兩種付費方式

🍱 月費方案（推薦新手）

像「吃到飽，但每 5 小時限量」。每月固定付錢，額度用完就等它重置，不會多扣錢。

  • ChatGPT：Free $0／Go $8／Plus $20／Pro $100 起
  • Claude：Pro $20（年繳約 $17／月）／Max $100 起
  • 額度大多以 5 小時為一個區間重置，另有每週上限
🚕 API 按量計費

像「計程車跳表」。用多少 token 付多少錢，沒有上限——也沒有天花板。

  • 以「每 100 萬 token」計價，分成輸入（AI 讀的）和輸出（AI 寫的）
  • 例：Claude Sonnet 5.5 輸入 $2、輸出 $10／每百萬 token
  • 適合工程師、公司，或想精算成本的人
🧮 粗估：做一個自我介紹網頁要花多少？

假設來回改 10 輪，AI 總共讀了約 50 萬 token、寫了約 5 萬 token，用 API 價格（Sonnet 5.5）計算：

0.5 百萬 × $2 ＋ 0.05 百萬 × $10 ＝ $1 ＋ $0.5 ≈ US$1.5

用月費方案的話，這只佔一小段額度，不會另外收費。實際用量會因模型、對話長度、檔案多寡而不同，這裡只是讓你有個數量級的感覺。

省額度三招① 一件事一個對話　② 先用 Plan Mode 想清楚，少走冤枉路　③ 不要一次丟一堆不相關的大檔案給 AI

※ 價格整理於 2026 年 10 月，以 OpenAI 與 Anthropic 官方價格頁為準。

04動手做第一個網頁

⏱ 約 30 分鐘✍️ 要動手🏆 完成後你會有自己的網頁
一句話重點開一個空資料夾 → 在 App 裡選它 → 貼上一段描述 → 打開 index.html 看結果 → 一次改一件事。

Step 0｜準備三樣東西

💻
一台電腦
Mac 或 Windows 都可以
🔑
一個帳號
ChatGPT（用 Codex）或 Claude 付費帳號（用 Claude Code）
📁
一個空資料夾
在桌面新增資料夾，取名 my-first-site

Step 1｜安裝 App 並登入

  1. 下載桌面 App 用 Codex：到 chatgpt.com 下載 ChatGPT 桌面 App。
    用 Claude Code：到 claude.com/download 下載 Claude 桌面 App，打開後點上方的 Code 分頁。
  2. 登入帳號用你平常的帳號登入即可。
  3. 選擇資料夾App 會問你要在哪個資料夾工作——選剛剛建立的 my-first-site。
    AI 只會在這個資料夾裡動手，不會亂碰你其他檔案。
🖥️ 進階：想用「終端機」版本？點我展開

終端機（Terminal）是一個用打字跟電腦溝通的視窗。Mac 按 ⌘+空白鍵 搜尋「終端機」；Windows 搜尋「PowerShell」。把下面指令貼進去按 Enter：

終端機 — 安裝 Claude Code（Mac）
# 安裝（只要做一次）
$ curl -fsSL https://claude.ai/install.sh | bash

# 進入你的資料夾，然後啟動
$ cd ~/Desktop/my-first-site
$ claude

Codex CLI 的安裝方式請參考 OpenAI 官方文件。第一次用建議先從桌面 App 開始，比較直覺。

Step 2｜跟 AI 說第一句話

在輸入框貼上這段（可以改成你自己的內容）：

你幫我做一個自我介紹網頁，存成 index.html。
內容：我叫小安，喜歡貓、咖啡和旅行。
風格：溫暖、可愛、米色系，手機上也要好看。
加一個按鈕，按下去會隨機出現一句今天的小語。
AI好的！我會建立 index.html，包含：標題與自我介紹、三個興趣卡片（🐱 ☕ ✈️）、一個「今日小語」按鈕……
✅ 已建立 index.html

Step 3｜打開看看

到 my-first-site 資料夾，雙擊 index.html，它會在瀏覽器打開。

或者直接跟 AI 說：「幫我在瀏覽器打開它」。

試試看第一次就看到自己的網頁，是很神奇的時刻 ✨ 截個圖留念吧！

Step 4｜用說的來修改

不滿意？直接說！一次改一件事，效果最好：

你標題字再大一點，換成手寫感的字體
AI✅ 已把標題改為 48px，使用手寫字體。重新整理頁面就能看到。
你按鈕按下去的時候加一點彈跳動畫，再多 10 句小語
AI✅ 已加入彈跳效果，小語增加到 15 句。
記得重新整理AI 改完檔案後，回到瀏覽器按 ⌘+R（Windows 按 F5）才會看到新版本。

怎麼「說」AI 才聽得懂？

😕 模糊幫我做一個網站AI 只能亂猜：什麼網站？給誰看？長什麼樣？
😊 清楚幫我做一個咖啡店介紹頁，有菜單、營業時間、地圖，風格要溫暖木頭色，手機上也好看有「做什麼、有哪些內容、長什麼樣」。
😕 只說結果壞掉了AI 不知道哪裡壞、怎麼壞。
😊 描述現象按「送出」按鈕沒有反應，我預期會跳出謝謝訊息說清楚「做了什麼 → 看到什麼 → 預期什麼」。
📝 萬用指令公式

我想做 【什麼東西】，給 【誰】 用，
裡面要有 【內容 1、2、3】，風格是 【形容詞】。
先不要寫程式，先告訴我你打算怎麼做。

最後一句很重要——這就是下一章的 Plan Mode 精神。

05Plan Mode：先想清楚，再動手

⏱ 約 6 分鐘✍️ 試一次
一句話重點改大東西之前，先讓 AI 只看不改、寫出計畫給你確認。Claude Code 按 Shift+Tab，Codex 輸入 /plan。

Plan Mode（規劃模式）就是請 AI 「先別急著改檔案，先跟我說你打算怎麼做」。

平常 AI 收到指令會直接動手。但如果需求比較大、或你自己也還沒想清楚，它可能會往你沒想到的方向衝。Plan Mode 讓 AI 先讀資料、問你問題、寫出計畫，等你點頭才開始改。

為什麼新手特別需要它？

🧭 不會迷路
你會先看到 AI 打算做哪幾步，心裡有底
🗣️ AI 會反問你
「要放照片嗎？」「要深色還淺色？」——幫你把模糊的想法說清楚
🛟 少走冤枉路
方向錯了在計畫階段就能改，不用等它寫完一大堆再重來

怎麼打開？

🟠 Claude Code

在輸入框按 Shift+Tab，切換到畫面顯示 ⏸ plan mode on 為止。桌面 App 也可以在輸入框旁的模式選單切換。

🟢 Codex

在輸入框輸入 /plan 開啟規劃模式，再描述你的需求。

Plan Mode 對話範例
> 我想把自我介紹頁改成作品集，放我的 6 張插畫

AI：開始之前想確認幾件事：
  1. 點插畫時要放大顯示嗎？
  2. 每張要附標題和說明文字嗎？
  3. 原本的「今日小語」按鈕要保留嗎？

> 要放大、要標題、按鈕保留

AI：📋 計畫
  1. 新增「作品集」區塊，3 欄排版（手機 1 欄）
  2. 建立 images/ 資料夾放 6 張插畫
  3. 點圖片時全螢幕放大，可左右切換
  4. 保留原本的自我介紹與今日小語
  要照這個計畫開始嗎？
⏸ plan mode on                 [ ✓ 批准並開始 ]  [ 繼續修改 ]
試試看就算沒有切換模式，你也可以在指令最後加一句「先不要動手，先告訴我你的計畫」——效果很接近。養成習慣，會少很多「欸怎麼變成這樣」的時刻。

06Skills：給 AI 的技能包

⏱ 約 10 分鐘🎨 設計師必看
一句話重點Skill 是一份「教 AI 怎麼做某件事」的說明書。裝上之後，AI 就會照著專家的做法工作——例如做出更有設計感的介面。

Skill 是什麼？

想像 AI 是一位很聰明、但剛到職的新同事。Skill 就是你交給它的「工作手冊」：遇到某種任務時，該照什麼步驟、注意什麼、做出什麼品質。

  1. 自動觸發你說「幫我設計一個登入畫面」，AI 發現有相關 skill，就會自己翻開來照做。
  2. 手動呼叫Claude Code 輸入 /skill名稱；Codex 輸入 $skill名稱 或 /skills 看清單。
  3. 兩邊通用Skills 遵循開放標準「Agent Skills」，同一份 SKILL.md 在 Claude Code 和 Codex 都能用。

07GitHub：存檔、時光機、免費上線

⏱ 約 25 分鐘✍️ 要動手🏆 完成後你會有公開網址
一句話重點GitHub = 雲端存檔＋版本時光機＋免費網站空間。註冊帳號後，上傳和上線都可以請 AI 幫你做。

GitHub 是一個放程式檔案的網站。對你來說，它有三個超實用的功能：

只要認識這幾個詞

Repository 倉庫／專案

簡稱 repo。就是放在 GitHub 上的一個專案資料夾。

Commit 存檔點

像遊戲的「存檔」。每次改到滿意，就存一個點，附上一句說明。

Push 上傳

把電腦裡的存檔點，推上 GitHub 雲端。

Pull 下載

把 GitHub 上最新的版本拉回電腦。

Git 記錄工具

在你電腦上負責記錄版本的小程式。GitHub 是放這些記錄的網站。

GitHub Pages 免費網站空間

把 repo 裡的網頁直接變成一個公開網址。

把你的網頁放上網（逐步）

  1. 註冊 GitHub 帳號到 github.com/signup 註冊。
    使用者名稱會出現在網址裡（例如 xiaoan.github.io），取一個你喜歡的、簡短的英文名字。
  2. 讓 AI 幫你連上 GitHub對 AI 說：
    你我是 Git 和 GitHub 新手。請幫我把這個資料夾上傳到 GitHub，建立一個叫 my-first-site 的公開 repo。每一步都用簡單的話告訴我你在做什麼，需要我操作的時候請停下來教我。
    第一次會需要登入 GitHub 授權，AI 會帶你完成（通常是跳出瀏覽器，點「授權」）。
  3. 打開 GitHub Pages可以請 AI 幫你開，或自己到 GitHub 網頁操作：
  4. 等 1–2 分鐘，拿到網址 🎉頁面上方會出現 https://你的名字.github.io/my-first-site/，打開就是你的網站，手機也能看，傳給朋友吧！
  5. 之後每次更新改完後跟 AI 說：「幫我 commit 並 push，說明寫『加入作品集』」。等一兩分鐘，網址上的內容就會更新。
公開 repo 誰都看得到不要把密碼、身分證字號、住址、私人照片、API 金鑰放進去。不確定能不能放的東西，先問 AI：「這個資料夾裡有沒有不適合公開的東西？」

08卡關了怎麼辦 & 下一步

⏱ 約 5 分鐘🔖 卡住時再回來看
一句話重點看不懂的錯誤 → 整段貼給 AI。改壞了 → 請 AI 回到上一個 commit。
🔴 出現一大串看不懂的紅字錯誤

完全正常！把錯誤訊息整段複製，貼給 AI，加一句「我看不懂，請用簡單的話解釋並幫我修好」。90% 的問題這樣就解決了。也可以直接截圖貼給它。

🌀 AI 改了半天越改越亂

這時候 GitHub 的「時光機」就派上用場：跟 AI 說「幫我回到上一次 commit 的版本」。然後開 Plan Mode，重新把需求說清楚一次。

💬 對話太長，AI 好像忘記前面說過的事

開一個新的對話，簡單交代：「這是一個自我介紹網頁，檔案是 index.html，我現在想要……」。乾淨的開始常常比硬撐有效。

🌐 push 了，但網址上還是舊的

等 1–2 分鐘，然後強制重新整理（Mac ⌘+Shift+R／Windows Ctrl+F5）。還是不行就問 AI：「幫我檢查 GitHub Pages 部署狀態」。

🤖 AI 要我同意執行某個指令，我該按嗎？

看不懂就先問：「這個指令會做什麼？安全嗎？」。一般的建立檔案、安裝套件通常沒問題；如果它說要刪除東西，先確認是不是你要的。
